# Kitmux v0.7 — Antigravity, a new look, and hardened CI

V0.7 adds the Antigravity CLI (`agy`) as a fourth client, redesigns the terminal
interface in red, grey, black, and white, and hardens the CI and release pipeline.
Catalog schema 3 is unchanged; v0.6 catalogs and journals load as they are.

## Antigravity CLI

Use the client ID `antigravity` anywhere a client is accepted: `--agent`, `--from`,
group `--agents`, and `--format`. Kitmux manages:

- MCP servers in `~/.gemini/config/mcp_config.json`, the file `agy mcp` and the
  Antigravity IDE share. HTTP endpoints use `serverUrl`; imported entries turn off
  with `"disabled": true`, and entries Kitmux created are removed. Defaults that
  `agy` drops when it rewrites the file are not conflicts, and the empty file `agy`
  creates on first start reads as no servers. Legacy SSE and `httpUrl` are refused.
- Skills linked into `~/.gemini/config/skills`. Because `agy` also reads the shared
  `~/.agents/skills`, a skill that is off for Antigravity is added to `exclude` in
  `~/.gemini/config/skills.json`; Kitmux owns only the names it adds.
- Subagents in `~/.gemini/config/agents/<id>.md` (or an imported `<id>/agent.md`),
  with the `antigravity` native format. Portable profiles render name, description,
  and body only.

Qualification used `agy` 1.5.17 (which includes 1.5.16) in a sandboxed temporary
home with offline commands only; `make test-native` now includes it on macOS.

## Terminal interface

Red marks the brand, the active tab, the selected row, and warnings; grey carries
secondary text, OFF states, hints, and rules; the terminal's own colors provide
white and black, so light and dark themes both read well. `NO_COLOR` keeps the
attribute-only fallback. Client columns follow the supported clients, the name
column fits the longest visible name, and UTF-8 terminals show compact state
symbols. Documents open with a one-line client summary.

## CI and releases

A single required `ci-ok` gate covers workflow linting (actionlint, zizmor),
cppcheck (`make analyze`), and the ordinary and ASan/UBSan suites on four targets.
CodeQL, a Conventional Commit title check, and Dependabot run alongside. Every
action is pinned to a commit SHA with least-privilege permissions, and tagged
releases attest build provenance for each archive and `SHA256SUMS`
(`gh attestation verify`, see the [guide](GUIDE.md#continuous-integration-and-release-provenance)).

## Upgrade and rollback

Install v0.7 and restart coding clients. To adopt Antigravity, run
`kitmux import --from antigravity --preview`, then `--apply`, or
`kitmux sync --preview --agent antigravity`.

A catalog that mentions `antigravity` cannot be read by v0.6, which stops with an
"Invalid agent override" error and writes nothing. To roll back, run
`kitmux restore --agent antigravity --apply` with v0.7, then remove the
`antigravity` keys from the catalog and the Antigravity records from the ownership
journal, or restore your backups, before starting v0.6.
